## Exploratory Data Analysis Project: Restaurant Tips Analysis

### Project Files:
- `EDA final project.ipynb` - Complete Jupyter Notebook with full analysis
- `tips_analysis_cleaned.csv` - Cleaned and processed restaurant tips dataset
- `analysis_summary.txt` - Summary of key findings and insights

### Project Requirements Met:
- ✅ Dataset with 150+ rows and 7+ columns
- ✅ 5 visualizations created (histograms, bar charts, scatter plots, etc.)
- ✅ 5 analytical questions answered with data evidence
- ✅ Data cleaning and preparation performed
- ✅ Statistical analysis (correlations, means, distributions)
- ✅ Detailed markdown explanations throughout

### Key Findings:
- Average tip percentage: 15.8%
- Thursday lunch has highest tips (21.9% average)
- Strong correlation between bill amount and tip (0.799)
- Non-smokers tip better than smokers
- 4-person parties are most profitable for restaurants

### How to View:
1. Open `EDA final project.ipynb` in Jupyter Notebook
2. Run cells sequentially to see the complete analysis
3. View visualizations and business insights
